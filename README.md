# HC Sharks Kids MCP

Локальный stdio-сервер для личного кабинета ученика [HC Sharks Kids](https://hcsharkskids.tvoyklass.com/). Работает на macOS с Python 3.11+.

## Первый вход и подключение

В Terminal откройте каталог проекта и выполните команды. Для установки зависимостей требуется `uv`.

```sh
uv run --locked python credentials.py
```

Введите email и пароль кабинета. После успешного входа программа сохранит их в Связке ключей macOS под именем `sharks-mcp.hcsharkskids.tvoyklass.com`. При смене пароля запустите настройку ещё раз. Для удаления сохранённого доступа удалите эту запись в приложении «Связка ключей».

Для подключения к Codex выполните один раз из каталога проекта и откройте новый чат.

```sh
codex mcp add sharks_mcp -- "$(command -v uv)" run --locked --directory "$PWD" python server.py
```

Для других stdio-клиентов используйте ту же команду запуска с абсолютными путями к `uv` и каталогу проекта. При запуске `uv` синхронизирует окружение с `uv.lock`, включая поддержку SOCKS-прокси. Каждая операция открывает HTTPS-сессию. Cookies и CSRF-токен хранятся в памяти до завершения вызова.

## Инструменты

| Инструмент | Пример запроса | Результат |
| --- | --- | --- |
| `get_schedule` | Какие тренировки есть на следующей неделе? | Занятия за период, идентификатор тренировки, время, группа, место, число свободных мест при наличии |
| `get_my_bookings` | На какие тренировки я записан? | Расписание с фильтром личного кабинета «Мои» |
| `book_training` | Запиши меня на тренировку № 12345 | Запись на одно конкретное групповое занятие. Для новой группы кабинет может создать заявку на вступление |
| `cancel_booking` | Отмени мою запись на тренировку в субботу в 10:15 | Отмена одного занятия по `lesson_id` из «Моих записей» с учётом срока отмены в филиале |
| `get_subscriptions` | Когда заканчивается мой абонемент? | Даты окончания активных абонементов, включая семейные. Для истории передайте `include_inactive=true` |

Оба инструмента расписания принимают `start_date` и `end_date` в формате YYYY-MM-DD, обе границы входят в период. По умолчанию период начинается сегодня по московскому времени и длится семь дней. Время занятия относится к часовому поясу филиала. В семейном аккаунте укажите `student_id`. Если он пропущен, сервер покажет доступные имена и идентификаторы для выбора.

Перед записью сервер сверяет профиль, занятие, окно записи и доступность мест. Пересечение с другим занятием требует явного выбора `allow_time_overlap=true`. После отправки сервер запрашивает занятие повторно. Статус `booked` означает, что запись появилась в кабинете, `already_booked` — что она уже была. При потере ответа или статусе `submitted_unconfirmed` проверьте «Мои записи» перед повторной попыткой.

После отмены статус `cancelled` подтверждает, что запись исчезла из кабинета. Статус `not_booked` означает, что у выбранного ученика уже нет записи на это занятие. При статусе `submitted_unconfirmed` проверьте результат через `get_my_bookings`.

## Проверка

```sh
.venv/bin/python -m unittest -v
```

Тесты используют имитацию HTTP API. Запросы к клубу для входа, расписания, записей и абонементов основаны на веб-интерфейсе ученика и могут измениться вместе с ним.
